# Telega Desktop badges

This public registry supplies profile badges to Telega Desktop. The client reads badges.json anonymously.

Entries consist of a numeric Telegram ID and a badge type (supporter or developer). Add a recipient only after they consent to having those fields published, including in Git history. Revoking a badge removes it from the current list.

The owner can grant and revoke badges from Support → Manage badges in Telega Desktop. Use a fine-grained GitHub token scoped to this repository with Contents read/write permissions.
